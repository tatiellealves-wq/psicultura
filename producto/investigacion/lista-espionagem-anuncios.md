# 🔎 Lista de espionagem — Biblioteca de Anúncios do Meta

> **Como usar:** esteja **logado no Facebook**, clique no link → abre a Biblioteca de Anúncios
> mostrando **todos os anúncios ATIVOS** daquele dono. Os links de PÁGINA ("ver todos") são os
> melhores: ficam sempre atualizados. Os links de anúncio individual servem pra ver um criativo
> específico (podem expirar quando o anúncio para).

> Dica: dentro da Biblioteca, olhe **quantos anúncios** a página tem e **há quanto tempo** rodam.
> Muitos anúncios + muito tempo = está ganhando dinheiro = vale copiar.
